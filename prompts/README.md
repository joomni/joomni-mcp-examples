# Prompt library

Copy a prompt into Claude, ChatGPT or any connected app. Each one says which areas your key needs and what will happen. Anything that changes your store asks you to confirm first.

Many apps also offer Joomni's **built-in prompts** (`daily-briefing`, `build-page`, `seo-audit`…) from their prompt menu; see [built-in prompts](../docs/prompts-and-resources.md).
