# Security

Please report vulnerabilities in the Joomni MCP server privately to **security@joomni.com** rather than in a public issue. Prompt-injection findings (a store's own data making a model take an action) are in scope and welcome.

Never paste a connection key (`joomni_mcp_…`) into an issue, a screenshot or a committed config. Commit configs with a placeholder or an environment variable, as the files in `configs/` do. If a key leaks, revoke it in **Settings › MCP Connections**.
